# Mumbai Road Rage 🏍️

A zero-dependency, original Mumbai-inspired arcade motorcycle racing game.

## Play
Open [index.html](index.html) in a browser, or enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**.

## Controls
- **W / ↑** Accelerate
- **S / ↓** Brake
- **A / D or ← / →** Steer
- **Space** Punch rival bikers
- On mobile: use on-screen touch buttons.

## Goal
Finish the 3 km Marine Drive-inspired course while avoiding taxis and BEST buses. Knock out rival bikers to earn points.

## Tech
Single HTML file with Canvas 2D and vanilla JavaScript. No packages or build step.

## Roadmap
